# Guest Lecture

**Network Traffic Analysis · 200 points**

A student resources portal for computer engineering: past papers, slides, one
folder per course. The admin creates every account by hand and hands out a VPN
key to reach the site.

One student's account and key leaked. **Somebody attended on them.**

Work out what the visitor did while they were inside.

### What you have been given

- `syriaCTF-networkTraffic-challenge.pcap` — the capture, about 66 MB


### What you need

Wireshark or tshark, and nothing else. Entirely offline. The capture is large
enough that a display filter will serve you better than scrolling.
