# Al-Kindi CTF — challenge files

Seven challenges. One folder each. Open the folder you are working on and read
its README first.

| category | challenge | points | where it lives |
|---|---|---|---|
| Forensics | KindiSpider | 100 | files in this folder |
| OSINT | The Pizza Incident | 150 | files in this folder |
| Network Traffic Analysis | Guest Lecture | 200 | files in this folder |
| Web | Facecook | 250 | https://ctf.anashamidi.com/ |
| AI | Support Desk AI | 300 | https://llm.syriactf.com |
| Android | SecureVault | 400 | files in this folder |
| Pwn | Eden | 500 | http://bin.syriactf.com |

**1900 points in total.** Solve them in any order; nothing is gated behind
anything else.

Submit flags on the board: **https://dashboard.syriactf.com**

Flags look like `SyriaCTF{...}`. Case does not matter, and neither do stray
spaces.

Read `RULES.md` before you start. The short version: do it yourselves, AI is
out except on Eden, do not contact anyone you come across while solving, and be
ready to explain how you got a flag.
