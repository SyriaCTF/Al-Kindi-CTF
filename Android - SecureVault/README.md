# SecureVault

**Android · 400 points**

An Android app with a vault behind a login. Getting logged in is the start of
this challenge, not the end of it.

### What you have been given

- `SecureVault.apk`
- one set of credentials:

```
ctfplayer / S3cur3P@ssw0rd!
```

### The backend

The app talks to one host and nothing else. Whatever you run it on needs
working network access to reach it, so check your emulator's networking before
you decide the app is broken.

### What you need

An emulator or a device you control, and the usual Android tooling for pulling
an APK apart and watching what it says on the wire.
